# Painted character surface references

The original `maziss-side-atlas.png` and `maziss-depth-atlas.png` are unchanged.
The painted 3D study samples these drawings for the portrait, hair, trousers,
boots, skin and satchel. The complete surfaces have fixed rest-space projection
coordinates that deform with their skin weights. They are not camera-facing
cards and source alpha never removes model triangles.

`maziss-clean-garment-reference.png` is a new, AI-generated texture preparation
image made with OpenAI image generation on 18 October 2026, using both original
atlases as image references. The request preserved the teal jacket, mustard shirt,
ink and painted wear, and removed the original baked-in bag, strap, tools and
body parts. Its three columns are front, side and back. The separate 3D bag and
strap must not be duplicated in the jacket painting. This garment reference is
new artwork consistent with the originals; it is not a previously approved
character turnaround. The original generated file is retained in workspace output.

The review shows actual model renders using these sources. It does not substitute
a newly generated still illustration for a render of the animated geometry.
Projection seams, facial registration and unfinished hands remain subject to
visual review. Do not promote this study to the Godot game without owner review.
